プライバシーポリシー

ITパスポート練習問題ラボ（以下「当サイト」）における、利用者の情報の取扱いについて説明します。

収集する情報

当サイトでは、氏名やメールアドレスなど、個人を特定できる情報の入力を求めることはありません。会員登録やログインの機能もありません。

学習記録の保存について

練習問題の成績と付箋の情報は、お使いのブラウザの「ローカルストレージ」という機能を使って、利用者の端末の中だけに保存します。この情報が当サイトの運営者や第三者に送信されることはありません。保存した情報は、トップページの「このブラウザの成績と付箋をすべて削除」ボタン、またはブラウザの閲覧データの削除によって、いつでも消せます。

アクセス解析について

当サイトでは、アクセス解析ツールは使用していません。なお、当サイトは GitHub Pages で公開しており、GitHub, Inc. がサーバの運用のために IP アドレスなどのアクセス記録を取得する場合があります。詳しくは GitHub のプライバシーに関する声明をご覧ください。

広告について

現在、当サイトに広告は掲載していません。今後、広告配信サービスを導入する場合は、導入前に本ポリシーを改定し、Cookie の利用目的と無効にする方法をこのページでお知らせします。

お問い合わせでいただいた情報

メールでお問い合わせいただいた場合、いただいたメールアドレスなどの情報は、お問い合わせへの回答のためだけに使用し、法令に基づく場合を除いて第三者に提供することはありません。

ポリシーの変更

本ポリシーの内容は、必要に応じて予告なく変更することがあります。変更後の内容は、このページに掲載した時点から有効になります。
